# Milestone 7D — Listing update Form

Milestone 7D adds one manually reviewed correction path to canonical Venue detail pages:

- **Report a problem with this listing.** opens a separate Google Form;
- the selected Venue name and stable Venue ID are prefilled;
- the report, optional name, and optional email remain in the private Form response store;
- no Apps Script processor or trigger is introduced;
- no Venue is changed, deleted, merged, relocated, reclassified, or published automatically.

The operator must check dependent Watch Party and Fan Intent references before any manual deletion, merge, relocation, or identity-changing correction. Milestone 7E is not included.
